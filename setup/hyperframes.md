# HyperFrames Setup

**Status: Nothing to set up.**

Unlike the other six apps, HyperFrames isn't a SaaS product you need an account or API key for — it's a video-composition framework/CLI already available in this Claude Code environment. Generating the personalized walkthrough MP4 from the captured Plane screenshots is done directly by Claude Code when that phase of the build is reached (Phase 2 in `CLAUDE_BUILD_SPEC.md`), no external credential required.

Still counts as one of the required external-app integrations for the hackathon submission — it's a real rendering pipeline producing a real deliverable, not a mock.
